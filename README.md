# Reserve Lens

An issuer cannot choose convenient publishers each epoch. Registration freezes one asset authority origin, one liability authority origin, and a minimum coverage ratio. Each later observation must advance the epoch and use those exact origins.

Validators extract exact dated integer totals from both public reports, preserve both content digests, and derive the basis-point ratio deterministically. The stored state is `COVERED`, `WATCH`, or `DEFICIT`; the LLM never chooses that label.

The interface is an optical aperture: two ledgers rotate into a single ratio image. Source addresses appear only while calibrating or observing.
